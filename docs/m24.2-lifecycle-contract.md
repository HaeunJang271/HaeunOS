# M24.2 Process Lifecycle Contract

Date: 2026-11-16  
States (PCB only): `FREE=0 READY=1 RUNNING=2 SLEEP=3 WAIT=4 ZOMBIE=5`

## Dual-stage EXIT

| Stage | Who | Effect |
|-------|-----|--------|
| 1 Host | `ecall_mux` `reap_pid` / `on_fault` | Windows, evt, IPC, svc, FDs, socks, AS scrub; `runs[]` clear |
| 2 Guest | `sys_exit` / `sys_fault_exit` | `ZOMBIE`, `orphan_reparent`, `wake_wait`, schedule |

`PCB FREE` happens only via parent `WAIT` or `APP_SPAWN` orphan memset (unused run slot).

## Transitions (tested)

| From | Event | To | Notes |
|------|-------|-----|-------|
| FREE | FORK / APP_SPAWN | READY | |
| READY | pick_next | RUNNING | |
| RUNNING | WAIT (no zombie) | WAIT | |
| WAIT | child EXIT + wake | READY | then WAIT completes → child FREE |
| RUNNING | EXIT / fault | ZOMBIE | + host stage 1 |
| ZOMBIE | parent WAIT | FREE | |
| ZOMBIE | SPAWN orphan scan | FREE (memset) | desktop no-WAIT path |

## Orphan policy

On EXIT/fault: every non-FREE child with `ppid == self` gets `ppid = PCB[0].pid` (init). Children are not killed. Init may `WAIT` reparented zombies. Desktop still relies on SPAWN reclaim when it never `WAIT`s.

## Explicit non-coverage

- Selective `WAIT(pid)` (ABI has no pid arg)
- PID uint32 wrap stress
- Memory-leak instrumentation / physical HID
