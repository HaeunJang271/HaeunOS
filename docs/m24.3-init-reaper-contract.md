# M24.3 Init Reaper Contract

Date: 2026-11-16

## Phase 0 findings

| Item | Actual |
|------|--------|
| PCB0 | Init/desktop user process; pid from boot |
| Desktop loop | EVENT_POLL / idle YIELD; **no** WAIT until shutdown/`close_all` |
| WAIT | Reaps one ZOMBIE with `ppid == self` or blocks |
| Orphan reparent (M24.2) | EXIT/fault → children `ppid = PCB0.pid` |
| SPAWN memset | Clears unused-slot ZOMBIE PCBs (fallback) |

Reparenting does **not** free a PCB; something must `WAIT`/`TRYWAIT` (or SPAWN memset).

## Dual-stage reminder

1. **Host** `reap_pid`: windows/evt/ipc/…/AS scrub (once per EXIT/fault).  
2. **Guest** PCB: `ZOMBIE` → `FREE` only via WAIT/TRYWAIT/SPAWN memset.

## Init reaping contract

1. **Discover adopted children:** PCB scan for `ppid == init.pid` (WAIT/TRYWAIT).  
2. **Detect termination:** child state `ZOMBIE` (after host stage-1 cleanup).  
3. **Exit status:** WAIT/TRYWAIT return `exit_code` in `r1` when a zombie is reaped.  
4. **ZOMBIE → FREE:** successful WAIT/TRYWAIT clears state + fd slots.  
5. **No child ready:** WAIT blocks; **TRYWAIT** returns `-1` and continues.  
6. **Multiple zombies:** each WAIT/TRYWAIT reaps exactly one; repeat.  
7. **SPAWN memset:** remains valid fallback; not removed.

## TRYWAIT (syscall 52)

Additive ABI: non-blocking reap of one own ZOMBIE, else `-1`. Does not change WAIT. Desktop idle: `TRYWAIT` then `YIELD`.

## Limitations

- Concurrent multi-orphan count bounded by AS=3.  
- Selective WAIT(pid) not provided.  
- Exit status discarded if SPAWN memset reclaims before WAIT.
