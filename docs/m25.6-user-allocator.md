# M25.6 Userland Allocator

Date: 2026-11-16  
Implementation: `userland/haeun_malloc.s` (linked into apps that need it).

## Arena

- VA `0x00109000`, size `4096` (fixed; no grow).  
- `heap_init` creates one free block covering the page.

## API

| Symbol | Behavior |
|--------|----------|
| `heap_init` | Reset arena free block |
| `malloc(size)` | First-fit; 8-byte align; NULL if size 0 / OOM / size>arena |
| `free(ptr)` | Validate range + used bit; coalesce forward; ignore bad/double-free |
| `calloc(n, sz)` | Overflow-checked `n*sz` via add loop; zero payload |
| `realloc(ptr, n)` | malloc+copy+free; stack-saved metadata (no caller `r8` clobber) |

## Block

8-byte header: `size|used0`, pad word. `size` includes header. Min block 16 bytes.

## Limits

No PMM, mmap, COW, or kernel allocator coupling. Not leak-certified beyond tests.
