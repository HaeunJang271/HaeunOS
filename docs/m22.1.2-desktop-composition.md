# M22.1.2 Desktop Composition and Window Layout

> **HISTORICAL (M22.2):** Pre-M22.1.3 **64×32** layout. Current shell is **320×180** with three tiles inside one window — [m22.1.3-target-desktop.md](m22.1.3-target-desktop.md).

## Investigation (startup “three windows”)

| Question | Finding |
|---|---|
| What are the three shapes? | **Desktop shortcut tiles** (Calc / Edit / Files), not application windows. |
| Auto-spawn at boot? | **No.** Idle `--persist` run never logs `app-env: spawn`. |
| Who paints them? | Guest PCB0 `shell_paint` in `userland/desktop_draw.s`. |
| Who places app windows? | Each app hardcodes `WIN_CREATE` x/y/w/h (calc/edit/files/filemgr). |
| Why FB looks “black”? | Full-window clear `0x00101828` (dark brown). Not an uncleared buffer (`black_count=0`). |
| Composition path | Single guest shell backing → `GFX_COMPOSE` (ECALL 23). Host chrome skipped for fullscreen `(0,0,64×32)`. |

M22.1.1 removed large letter glyphs and left color rectangles only; those tiles read as “overlapping windows” in the viewer.

## Rendering hierarchy (guest shell)

1. `WIN_FILL` desktop background  
2. Title strip + `WIN_DRAW_TEXT` **HAEUN** + status glyph  
3. Three shortcut tiles (fill + letter) + labels **Cal** / **Ed** / **Fil**  
4. Taskbar + **Start** + status keys **12**  
5. Optional Start menu text (`1:calc`, `2:edit`)  
6. Application windows (only after spawn) + host chrome on those windows  

Authoritative compose: guest `shell_compose` → ECALL 23. Viewer may call `chrome_present` afterward; fullscreen shell still skips decorations.

## Layout (64×32 client = screen)

| Region | Content |
|---|---|
| y=0..7 | Title strip, `HAEUN`, idle `-` / busy `*` |
| y=9..16 | Icons at x=4,24,44 with glyphs C/E/F |
| y=17..23 | Labels Cal / Ed / Fil (8×8 font; abbreviated to fit width) |
| y=24..31 | Taskbar, `Start`, key hints |

Abbreviations are required by the 8×8 font on a 64px-wide FB (`HAEUN`≈40px, full “Calculator” cannot fit three-up).

## Application window placement

| App | Position | Size | Notes |
|---|---|---|---|
| calc | (16,8) | 32×16 | Centered first window |
| edit | (18,9) | 32×16 | +2,+1 cascade |
| files | (20,10) | 32×16 | +4,+2 cascade |
| filemgr | (14,8) | 36×16 | Key `3` target; within bounds |

Shell remains visible around apps; z-order/focus unchanged (WIN_RAISE + chrome).
