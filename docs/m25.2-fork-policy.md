# M25.2 FORK Policy

Date: 2026-11-16

## Callers surveyed

FORK (`ECALL 5`) is required by: `proc_user.s`, `fault_proc.s`, M24.x lifecycle/orphan/parent_death/pid_reuse images, M25.2 policy test. **Failing FORK would break M17/M24.** ABI number unchanged.

## Chosen policy (not COW, not fail)

**Per-slot user code page copy** on successful FORK:

1. Allocate free PCB/AS slot 0..2 (unchanged).  
2. Copy parent **code PA** → child **code PA** (4 KiB).  
3. Set child L0 user-code PTE → child PA \| `0x1b`; `SFENCE`.  
4. Wipe child ustack page; set child `r13`/`r14` to child stack bounds.  
5. Child `r1=0`, parent `r1=child_pid`.

Implemented in `kernel/process/proc_fork_mem.s` (`fork_user_mem`), called from `sys_fork` after GPR copy.

## Not a full POSIX clone

- No data/heap segment copy (none exist).  
- Stack wiped (not parent stack image).  
- No COW.  
- Window/IPC host objects are not duplicated.

## Reclamation

FORK children may lack `runs[]`. `haeun_app_reap` scrubs slots 1–2 whose **PCB.pid** matches the exiting pid (in addition to SPAWN runs[]).

## Rejected alternative

Explicit FORK failure: incompatible with existing guest tests without ABI redesign.
