# M25.2 AS Ownership Contract

Date: 2026-11-16

## Slot table

| Slot | Owner | Use | Alloc | Free / scrub | Code PA | User VA | Stack PA | Scrub? |
|-----:|-------|-----|-------|--------------|---------|---------|----------|--------|
| 0 | Init/desktop PCB0 | Shell + shared kernel maps | Boot `map_slot0` | Session lifetime | `0x108000` | `0x108000` | `0x113000` | **Never** |
| 1 | SPAWN `runs[1].pid` or FORK child | App / forked child | SPAWN or FORK | EXIT/fault `haeun_app_reap` | `0x10C000` | `0x108000` | `0x114000` | Yes (slots≥1) |
| 2 | SPAWN `runs[2].pid` or FORK child | App / forked child | SPAWN or FORK | same | `0x10D000` | `0x108000` | `0x115000` | Yes |

PCB index 0..2 ↔ AS slot 0..2. PCB3 unused for runnable AS (FORK cap).

## Invariants (tested)

1. SPAWN exclusive: at most one `runs[slot].pid` per slot 1–2; NOSPC at capacity.  
2. FREE PCB + unused run → SPAWN may claim.  
3. After reap: code page zeros, user-code PTE cleared (slots 1–2).  
4. PTE remap only after validation + wipe in SPAWN; FORK remaps after page copy.  
5. SPAWN fails before mutate on bad HXF (no partial ownership).  
6. Reuse after scrub does not expose prior tag bytes.

## Slot 0 exclusion

Desktop/init owns slot 0; maps shared kernel RX + MMIO. Scrubbing would destroy the live shell image. Confirmed by code (`scrub_slot` `slot < 1`) and tests (sentinel survives reap).
