# M25.6 FORK × Heap Integration

Date: 2026-11-16

## Contract extension

FORK copies, in order: **code** → **ustack** → **heap** (each 4 KiB), then relocates SP, then READY.  
Implemented in `fork_user_mem` (`proc_fork_mem.s`). Child heap PTE set to child PA `| 0x17`.

## Isolation

Shared heap VA `0x109000` maps to distinct PAs per slot. Parent stores after FORK do not appear in child (and vice versa). Proven by `m25_6_heap_isolation_tests`.

## Failure / partial

Slot exhaustion still fails before PCB claim. READY remains after full clone including heap.

## Identity maps

`fill_k` installs kernel RW (no U) for PAs `0x10E000`/`0x10F000`/`0x110000` at L0 `+0x438`..`+0x440` so memcpy can target foreign heap PAs without touching user PTE at `+0x424`.
