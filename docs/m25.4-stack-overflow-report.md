# M25.4 Stack Overflow Report

Date: 2026-11-16

## Handling

1. User load/store in the guard page → MMU page fault (cause 5).  
2. Guest `sys_fault_exit`: record cause/tval/epc/pid at `0xA450`, mark ZOMBIE, reparent, schedule.  
3. Host `haeun_ecall_mux_on_fault` (when attached): log `stack-overflow` if tval ∈ guard, then reap/scrub.

Only the faulting PCB is killed; siblings continue (proven by parent markers after child overflow).

## FORK

- Guard pages are not cloned (unmapped / non-U; not part of ustack copy).  
- Child SP relocated into child `[base,top)`; independent guard applies.  
- Child overflow leaves parent ustack contents intact; slot reuse FORK overwrites child ustack from parent.

## Scrub / reuse

- Host scrub (slots ≥1) zeros ustack on reap when `fault_io` present.  
- Without host mux, guest WAIT frees PCB; next FORK/SPAWN overwrites ustack (tested via reuse child).
