# M25.5 Allocator Design (Minimum, Not Implemented)

Date: 2026-11-16  
Assumes a **fixed arena** mapped U\|RW in the process AS (see feasibility doc).  
**Status: design only — no malloc in tree.**

## API surface (target)

| Function | Semantics |
|----------|-----------|
| `malloc(size)` | Allocate ≥ size usable bytes; align; NULL on OOM/overflow |
| `free(ptr)` | Return block; no-op or trap on invalid (policy below) |
| `calloc(n, size)` | `malloc` + zero; reject `n*size` overflow |
| `realloc(ptr, size)` | Grow/shrink; may move; `NULL` ptr ≡ malloc; size 0 ≡ free |

Placement options for M25.6:

1. **Userland library** in the app image (preferred first cut) once kernel maps the arena.  
2. **Kernel ECALL** (`HEAP_ALLOC` / …) — only if userland cannot touch metadata safely; **ABI change**, needs explicit approval.

This design prefers (1) to avoid syscall churn.

## Strategy: first-fit freelist

| Choice | Rationale |
|--------|-----------|
| First-fit | Small code; adequate for ≤4–12 KiB arena |
| Best-fit | Slightly less fragmentation; more scan cost — optional later |
| Bump-only | Simplest but `free` nearly useless — reject for stated API |

### Block layout (proposed)

```
| header (size | flags) | payload (aligned) | optional footer |
```

- Header at least one `uint32_t` size (payload bytes) + flag bit **free/used**.  
- **Alignment:** 8-byte payload alignment (ISA loads are 4-byte; 8 eases future).  
- Minimum payload: 8 bytes so free blocks can store **next** pointer in payload when free.  
- Free-list: singly linked through free payloads; arena `free_head` in a known word at arena start (or static in `.data` if linked into user image — but user `.data` today lives in RX code page; **prefer header word inside heap PA**).

### Arena bootstrap

1. Kernel/SPAWN maps heap page(s), zeros PA.  
2. User/runtime writes one free block covering `(arena_size - metadata)`.  
3. EXIT/scrub zeros entire PA (allocator state discarded).

## Review items

| # | Topic | Minimum policy |
|---|-------|----------------|
| 1 | Strategy | First-fit |
| 2 | Free-list | Intrusive singly linked in free payloads |
| 3 | Header | size + free bit; no back-pointer required for first cut |
| 4 | Alignment | 8-byte |
| 5 | Fragmentation | Coalesce with next free on `free`; split on alloc if remainder ≥ min block |
| 6 | Double-free | Free bit check; on double-free → return without corrupt **or** fault process (prefer detect + no-op in lib; tests must cover) |
| 7 | Invalid ptr | Reject pointers outside arena or not payload-aligned to a header |
| 8 | Integer overflow | `calloc` / size+header checks; reject if `size > arena` or wrap |
| 9 | OOM | Return `NULL`; do not expand (fixed region) |
| 10 | Init / reclaim | Zero page at SPAWN/FORK child policy; scrub on reap |

## Non-goals

- mmap/munmap  
- Thread safety (single-threaded process-v1 apps)  
- Kernel heap (host `calloc` / guest kernel allocators are out of scope)  
- Claiming leak-freedom without tests

## Complexity bound

Keep allocator source **&lt; 300 lines** and unit-testable on host with a fake arena buffer before wiring guest PTE.
