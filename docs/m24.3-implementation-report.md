WAIT semantics unchanged. SPAWN orphan memset retained. No NPROC/AS/scheduler/COW/WM changes.

## Rationale for TRYWAIT

Blocking WAIT cannot run in desktop idle without hanging when no zombies exist. Unused `r2` on WAIT was unsafe (callers leave garbage). Additive syscall 52 is the smallest safe init idle reaper.
