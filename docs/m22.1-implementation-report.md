# M22.1 Implementation Report — Desktop Shell

Date: 2026-11-15

> **HISTORICAL (M22.2):** Written for the **64×32** M22.1 shell. Superseded visually/ABI-geometry by **M22.1.3+ 320×180** — [m22.1.3-target-desktop.md](m22.1.3-target-desktop.md). Tile **F** now launches registry **`files` (index 2)**, not `filemgr`.

## Summary

Guest `desktop.s` + `desktop_draw.s` painted a HAEUN shell on the then-current **64×32** framebuffer using WIN_*/EVENT_*/APP_* ECALLs. M21 persist loop, Esc shutdown, keys 1–4, and `--persist` budget policy were preserved (geometry later raised to 320×180).

## Layout (client under chrome title)

| Region | Content |
|---|---|
| Top strip | Dark bar + “HAEUN” + idle/busy mark |
| Icons | C / E / F blocks (calc / edit / filemgr) |
| Taskbar | Accent launcher slot + “123” hints |
| Space / start slot | Toggles start-menu overlay |

## Files

| Path | Role |
|---|---|
| `userland/desktop.s` | Event loop, spawn/WAIT, hit-test, Esc |
| `userland/desktop_draw.s` | `shell_paint` / rect / icons |
| `tools/build_process_desktop.py` | Links both user objects |
| `tools/build_process_image.py` | `extra_sources` support |
| `tests/m22_1_desktop_shell_tests.py` | PPM + launch + persist regression |
| `build/m22_1_shell.ppm` | Visual screenshot artifact |

## Non-goals / PARTIAL

- No clock (no guest time ECALL).
- No drag/resize.
- 8×8 font limits labeling to single letters / short ASCII.
- Physical HID not claimed unless manually performed.

## Compatibility

- M21 keys/NOSPC/Esc unchanged.
- Idle: YIELD + compose every 64 yields.
- Apps still `APP_SPAWN` + `WAIT`.

## Verification

- `make clean && make all && make test`: **PASS** (includes m21 / m21.3 / m22.1).
- Automated screenshot: `build/m22_1_shell.ppm`.
- Physical HID: **not** claimed.
