## Key facts (code-backed)

- Guest RAM: **256 MiB** host buffer; process-v1 uses **3 static AS**.  
- App code: VA `0x00108000`, ≤4 KiB, per-slot PA, PTE RXU.  
- Stack: 4 KiB/user AS; **no heap** on process-v1.  
- SPAWN: wipe + load + PTE remap + TLB flush; reap scrubs slots 1–2.  
- FORK: PCB/context only — **not** memory clone.  
- MMU protection exists; foundation `kernel/mm` is a **separate** boot path.

## M25.2 priority (proposed)

1. Region ownership map + tests  
2. FORK memory policy (page copy or hard fail) + scrub gaps  
3. Then guard pages / optional heap — not COW yet
