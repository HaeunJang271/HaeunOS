# R4.1 Project Limitations

Inherits R4.0 limits (`docs/r40-limitations.md`) plus:

- Related-work coverage is selective (15 sources); not exhaustive of all adaptive OS literature.
- Full-text access incomplete for some IEEE/ACM articles (metadata+abstract only).
- Differentiation is qualitative; no head-to-head benchmarks vs Rainbow/K42/Linux.
- Standard campaign strengthens evidence but does not complete confirmatory science.
- Reproduction docs assume Make/C17/Python on Windows-like or POSIX hosts; truly clean external CI not claimed unless executed.
