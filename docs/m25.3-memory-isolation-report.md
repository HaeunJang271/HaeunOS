# M25.3 Memory Isolation Report

Date: 2026-11-16

## Private memory map (per AS slot)

| Region | VA (slot0 / 1 / 2) | PA | User PTE | FORK action |
|--------|--------------------|----|----------|-------------|
| Code | `0x108000` (all) | `0x108000` / `0x10C000` / `0x10D000` | `0x1b` U\|RX | Page copy + child PTE |
| Ustack | `0x113000` / `0x114000` / `0x115000` | same as VA | `0x17` U\|RW | Page copy + SP relocate |
| Kernel RX / MMIO | shared maps | shared | no U / MMIO | Not cloned |

## Isolation properties

- **Ustack:** verified by guest — child retains pre-FORK snapshot; parent post-FORK stores do not appear in child; child stores do not appear in parent (`m25_3_fork_isolation`).  
- **Code PA:** distinct after FORK; content snapshot readable (`m25_3_fork_snapshot`). User cannot store to RX code; write-isolation of code is via separate PA + reap scrub, not guest stores.  
- **Data/BSS:** no dedicated pages — N/A.

## Lifecycle / failure

- Child-only EXIT then parent WAIT: snapshot + isolation + failure images.  
- AS full (3 live PCBs): third FORK → `-1`, parent prints `F` then reaps (`m25_3_fork_failure`).  
- Partial child: PCB stays FREE until `fork_user_mem` returns; then READY.
