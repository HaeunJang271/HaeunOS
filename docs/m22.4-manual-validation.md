# M22.4 Manual Validation Guide

Use a real Windows keyboard/mouse with the live viewer.  
**Scripted automation and framebuffer dumps must not be recorded as physical HID PASS.**

## Input modes (do not conflate)

Inspected against `src/main.c` and `src/vm_viewer_win32.c`:

| Mode | Flags | What it does |
|------|-------|----------------|
| **Win32 viewer live input** | `--viewer` | `haeun_vm_viewer_attach(..., live_input=1)`. `WM_KEY*` / mouse messages feed the guest. **This is the path for manual HID checks.** |
| **`--input`** | `--input` (optional `--input-script NAME`) | Loads a host input script into `input_host`. Alone, runs `haeun_vm_input_host_run`. With `--viewer`, attaches the same script to `viewer.script` for replay **inside** the viewer loop. |
| **`--input-script`** | `--input-script PATH` | Selects which named script to load **and enables input mode** (`input_mode = true` in `src/main.c`). A separate `--input` argument is **not** required. Still **scripted**, not physical HID. |

For manual validation, prefer:

```powershell
.\build\haeun-vm.exe .\build\process_desktop.hxf --apps --persist --viewer
```

Do **not** add `--input` / `--input-script` when you intend to exercise a real keyboard and mouse. Mixing them can inject scripted events alongside live input.

## Build & launch

```powershell
make all
.\build\haeun-vm.exe .\build\process_desktop.hxf --apps --persist --viewer
```

(Rebuild desktop apps via the usual `make` / test harness if `process_desktop.hxf` is missing.)

Scale ≈ 2 → client ~640×360. Esc on the **shell** (click header first if an app has focus) shuts down.

|-----|--------|
| `1` / `2` / `3` | Spawn calc / edit / files (shell focused) |
| `4` | NOSPC probe (optional) |

| Editor | Letters/digits/Space/Enter/Backspace |

## Physical vs scripted

| Path | Status |
|------|--------|
| `--input-script` / M22.3–M22.4 automation | Automated — **not** physical HID |
| Framebuffer `--fb-dump` / PPM OCR | Snapshot evidence — **not** physical HID |
| `--viewer` + real keyboard/mouse | Code path in `src/vm_viewer_win32.c` — fill table above only after live use |

App registration in console logs (`apps: registered …`) does **not** by itself prove interactive usability.
