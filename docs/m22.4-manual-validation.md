# M22.4 Manual Validation Guide

Use a real Windows keyboard/mouse with the live viewer.  
**Scripted `--input` / `--input-script` results must not be recorded as physical HID PASS.**

## Build & launch

```powershell
make all
.\build\haeun-vm.exe .\build\process_desktop.hxf --apps --persist --viewer --input
```

(Rebuild desktop apps via the usual `make` / test harness if `process_desktop.hxf` is missing.)

Scale ≈ 2 → client ~640×360. Esc on the **shell** (click header first if an app has focus) shuts down.

## Checklist

Record one of: **PASS** / **FAIL** / **NOT TESTED**.

| # | Step | How | Expected | Result |
|---|------|-----|----------|--------|
| 1 | Desktop launch | Start command above | Header `HAEUN-OS`, welcome, 3 tiles, taskbar; no black flash loop | |
| 2 | Calculator + keys | Key `1` or click Calc tile; type digits/ops; Enter | Window opens; display updates; Esc closes app | |
| 3 | Editor + text | Key `2` or Edit tile; letters/digits/Space; Backspace | Text appears/erases; Esc closes | |
| 4 | Files list | Key `3` or Files tile | Title `Files`; registry names visible; Esc closes | |
| 5 | Desktop resume | After each Esc on app | Shell tiles/taskbar visible again; no freeze | |
| 6 | Repeat launches | Open/close calc twice, then edit | Second spawn works; no fault spam | |
| 7 | Mouse focus | Click app chrome/client, then click shell header | Keys go to focused surface; shell receives spawn keys after header click | |
| 8 | Esc shutdown | Focus shell header; Esc | Clean halt / window close; `r1=0` if console visible | |
| 9 | Long run | Leave idle ≥ 5 minutes under `--viewer --persist` | No crash; UI still responsive | |

## Key map (guest)

| Key | Action |
|-----|--------|
| `1` / `2` / `3` | Spawn calc / edit / files (shell focused) |
| `4` | NOSPC probe (optional) |
| Esc | Close focused app **or** shutdown shell if shell focused |
| Calc | Digits, `+`/`=` , `-` , `x` , `/` , Enter, Backspace |
| Editor | Letters/digits/Space/Enter/Backspace |

## Physical vs scripted

| Path | Status |
|------|--------|
| `--input-script` / M22.3–M22.4 automation | Automated — **not** physical HID |
| `--viewer` + real keyboard/mouse | Code path in `src/vm_viewer_win32.c` — fill table above only after live use |

## Fail notes

If FAIL: note step #, scancode/focus observation, and whether console showed `[haeun-fault]` or `STEP_LIMIT`.
