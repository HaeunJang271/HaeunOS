## Measurable resource evidence

Printed by `m23-4-resource-tests`:

- `used` slot count before/after owner exit (`used_after=0`)  
- `focus_id` eligibility after every transition  
- `owner_pid == 0` on destroyed slots  
- `evt_queued == 0` after `haeun_evt_reap`  
- `next_z` monotonic (logged)  

**Not claimed:** heap leak freedom (no malloc in WM table path; slot reuse is the measurable reclaim model).

## Explicitly untested

- Physical HID / real keyboard-mouse devices  
- Viewer Win32 frame timing  
- Strip-button un-minimize (strip only raises; restore tested via `haeun_gfx_wm_restore` on host)  
- Host timeout-destroy after soft CLOSE  
- Leak detectors (ASan/Valgrind) on the host process
