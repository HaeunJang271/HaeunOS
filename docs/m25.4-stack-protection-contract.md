## Protection method: real MMU guard (not canary)

| Slot | Guard VA | Mechanism |
|-----:|----------|-----------|
| 0 | `0x112000` | L0 PTE cleared (`V=0`) after `fill_k` |
| 1 | `0x113000` | L0 PTE cleared (`V=0`) |
| 2 | `0x114000` | Kernel RW identity **without U** (FORK memcpy needs PA); user → fault |

Valid user stack: `[ustack_base, ustack_top)`. Access in `[base-4096, base)` is a stack overflow.

## ABI

No syscall/ABI changes. Fault logging may print `stack-overflow` when `fault_io` is installed.
