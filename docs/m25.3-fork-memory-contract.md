## Contract

1. Child receives a clone of parent **user code page** and **ustack page** at FORK.  
2. Parent and child **private** pages (distinct PAs) are independent after FORK.  
3. A store by one process must not change the other's private ustack (or code PA).  
4. User code remains **RX** (shared-by-content at clone time, not shared-by-PA; not COW).  
5. ABI: child `r1=0`, parent `r1=child_pid`, PC past ECALL — unchanged.  
6. Slot exhaustion returns `-1`; parent GPRs/PC/AS unchanged aside from return value.  
7. Child EXIT/reap must not scrub parent memory.

## Unsupported (not claimed)

- Separate data/BSS/heap segments (none exist in process-v1 layout).  
- COW.  
- Host window/IPC object duplication.  
- Mid-copy fault injection (clone path is linear; failure is pre-alloc only).
