### Graphics ECALLs (guest)

| ECALL | Number | Role |
|---|---|---|
| `WIN_CREATE` | 18 | Window + backing (process pool when pid≠0) |
| `WIN_DESTROY` | 19 | Destroy |
| `WIN_FILL` | 20 | Fill entire window backing |
| `WIN_PIXEL` | 21 | Single pixel |
| `WIN_RAISE` | 22 | Z-order + focus |
| `GFX_COMPOSE` | 23 | Composite WM → FB (no host chrome) |
| `EVENT_POLL` | 27 | Per-pid input / window events |
| `WIN_DRAW_TEXT` | 28 | ASCII 8×8 text |
| `WIN_QUERY` | 37 | Geometry |
| `WIN_FILL_RECT` | 51 | Rect fill |

### Shell ownership

PCB0 image: `userland/desktop.s` + `desktop_draw.s` → `process_desktop.hxf`.  
One fullscreen shell window holds **header, welcome, three tiles, bottom bar** as pixels (not separate WM windows). Apps are separate WM windows; host chrome may decorate non-shell windows.

### Launch map

| Key / tile | Registry index | App |
|---|---|---|
| `1` / Calculator | 0 | `calc` |
| `2` / Editor | 1 | `edit` |
| `3` / Files | **2** | `files` (not `filemgr`) |
| `4` | NOSPC probe | spawns fillers then CLOSE/WAIT |
| Esc | — | shell shutdown (after `close_all`) |

Spawn uses `APP_SPAWN` **without** waiting for exit; apps persist until Esc/CLOSE.  
`--persist` unbounded budget; `--apps` required to register builtins.

### Testing posture

- Shell layout / persist / spawn: covered by `tests/m21_*`, `tests/m22_1_*`.
- Calculator/Editor interactive typing: **implemented in source**; not comprehensively automated.

## HISTORICAL — original M22.1 64×32 sketch

The following was the pre-M22.1.3 inspection target and is **obsolete** for runtime:

- FB 64×32 @ `0x10000`
- Shell at `(0,6)` size `64×26`
- Launch `count-1` → filemgr with `WAIT` after spawn
- “No guest rect-fill ECALL” (superseded by ECALL 51)

Keep only for archaeology of early M22.1 notes.
