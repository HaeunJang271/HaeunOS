# M22.3 Interactive Application Verification

Date: 2026-11-16  
Resolves audit **D4** ([m22-desktop-specification-audit.md](m22-desktop-specification-audit.md)).

## Goal

Prove Calculator, Editor, and Files receive **guest-level** keyboard input through the real `--input` / chrome / `EVENT_POLL` path — not host-only helpers — and that the desktop survives app exit.

## Guest key map (from source)

| App | Scancodes |
|-----|-----------|
| Desktop spawn | `1`=0x02 calc, `2`=0x03 edit, `3`=0x04 files, Esc=0x01 |
| Calculator | digits 0x02–0x0B; `+`=0x0D/0x4E; `-`=0x0C; `*`=`x` 0x2D/0x2C; `/`=0x35; Enter=0x1C; BS=0x0E; Esc=0x01 |
| Editor | XT set-1 → ASCII via `scan2asc`; Space=0x39; BS; Esc |
| Files | Esc / CLOSE only (list is draw-once) |

## Harness

- New scripts: `haeun_vm_input_host_load_m22_3_script` in `src/vm_input_m22_scripts.c`
- CLI: `--input-script NAME` (with `--apps --persist`)
- `HAEUN_INPUT_HOST_MAX_EVENTS` raised to **64** (host-only)
- Test: `tests/m22_3_interactive_app_tests.py`
- Observable proof: `--fb-dump` PPM + 8×8 font OCR (same bitmaps as `src/gfx_font.c`)

| `life-cycle` | calc/edit/files + repeat calc; halt ≥ 560000 steps |

## Guest fixes required for real interaction

(ABI unchanged; app images only.)

1. **calc / edit** — `on_key` link saved on stack; `paint`/`draw_num` clobbered `r11`.
2. **calc** — `div10`/`mul10`/`imul`/`idiv` scratch moved off `r3`/`r4` (glyph x/y).
3. **files** — `APP_NAME` capacity **15** (`>= 16` rejected by host).

## Limitations (intentional)

- **Not** physical HID certification — scripted Win32/host feed only.
- Division by zero → guest shows `0` (existing behavior); not separately asserted.
- Multiply coverage uses single-digit result (`2×2`); multi-digit arithmetic is covered by add/sub display path + `calc-bs`.
- OCR asserts exact FONT8 bitmaps; does not fuzz layout chrome.
- Existing M21 10M+ persist stress remains in `m21_3_*` / `m22_1_*` (not duplicated here).
